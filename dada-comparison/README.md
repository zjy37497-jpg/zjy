# 搭练：无云函数前后对比 Demo

两个独立的微信小程序工程，沿用上传包的界面。没有云函数、云数据库、wx.cloud，也不需要部署后端。小程序通过 wx.request 直接调用兼容 Chat Completions 的模型 API。

| 文件夹 | 用途 |
| --- | --- |
| before | 基础版：一句系统提示词，不装载 Skill，不检索知识，不读写档案 |
| after | 增强版：Skill 规则 + 本地关键词 RAG + 本机档案工具，三个能力可独立开关 |

## 先跑起来

1. 下载本仓库 ZIP 并解压，打开微信开发者工具，选择“导入项目”。
2. 目录选 `dada-comparison/before` 或 `dada-comparison/after`，不要选仓库最外层。
3. 使用你自己的小程序 AppID；仅模拟器演示也可选择测试号。项目没有云开发依赖。
4. 编译后，点击聊天页上方“接口设置”。填模型服务的基础地址、模型名、API Key。地址不带 `/chat/completions`，由程序自动追加。使用支持工具调用的模型。
5. 两个版本填同一个模型、地址。默认智谱地址为 `https://open.bigmodel.cn/api/paas/v4`，模型字段是可修改的示例；以你的服务账户中实际可用模型为准。硅基流动请填写其兼容接口基础地址与账户中的完整模型 ID。
6. 如果模拟器报 request 域名错误，检查开发者工具详情中的域名校验选项。本项目 `urlCheck` 为 false，便于本地开发。真机与正式环境需要满足微信域名配置要求。
7. 保持页面显示“直连 AI”。“本地示例回复”是离线演示，不参与 AI/RAG 效果对比。
8. 增强版需进入“个人档案”点击“开启记忆”，才能记录和调用档案。开启时会说明档案会发送给配置的模型。

API Key 只保存在本次运行内存，不写入文件或本地缓存，也不在日志输出。重新编译/退出后需重填。基础版与增强版的设置缓存相互隔离。前端直连仅用于个人开发演示；公开发布需改成由可信服务端保管密钥，可使用普通 HTTPS 后端，不必使用云函数。

## 怎么录前后对比

- **Skill 对比**：两个版本都开新对话；增强版只开 Skill，关 RAG、档案工具。两边同问“今天练得很累，不想坚持了”。Skill 使用原包内规则，未额外加可爱人设。
- **RAG 对比**：在增强版保持其他开关一致，仅切换 RAG。分别新对话问“深蹲时应该注意什么？”或“训练中断后怎么调整？”。回答下方出现 `search_knowledge: found` 才代表实际命中，后面列出命中文章标题；`empty` 表示未命中。模型未调用工具时不会伪造检索记录。
- **档案读写**：开启档案工具和记忆，说“我的长期目标是增肌”，查看 `update_user_profile: applied` 与档案页。清空聊天后问“根据我的目标给我建议”，检查 `get_user_profile` 调用及回答是否运用了档案。
- **更正**：说“把我的目标改为减脂”，确认原记录被更正而非重复新增；也可以在档案页直接更正。
- **敏感信息**：健康记录需要弹窗确认。取消后不会保存。删除操作也需确认。
- **管理**：档案页支持删除单条、清空并关闭记忆、停用与重新启用。关闭记忆后不会把旧档案提供给模型；清空聊天不删除档案。关闭记忆/切换接口开关后重开对话避免旧上下文干扰。

两个版本使用相同温度 0.5、最大输出 1400 tokens、最近 16 条上下文。模型回复并不保证每次一致。对比单一能力时，保持其他开关和输入一致，重复测试多次，不要把整套增强版与基础版的差异全部归因于 RAG。

## 实现与边界

- 原云端 Skill 内容转为 `after/utils/prompts.js` 中的运行时提示词。原始 `skills/` 文件保留作参考。Skill 不是微信原生能力，而是注入模型的规则。
- 原知识库与关键词召回逻辑迁到 `after/utils/knowledge.*`。检索最多返回 3 条，结果送给模型生成回答。这是本地关键词 RAG，不是向量检索，也没有连接 Dify、Embedding 或远程知识库。
- 档案存于 wx 本地缓存，仅本机/该小程序可用，不是微信账号云端档案，不跨设备同步。清缓存或卸载会丢失。默认记忆关闭，避免未经开启自动采集。
- 调用记录来自真实工具执行结果，独立于聊天正文显示，不作为模型历史再次发送。
- AI 模式已移除原包普通固定回复拦截；保留两个版本一致的紧急情况提示。离线模式仍提供固定示例，并明确标注。
- RAG、档案由模型工具调用驱动，需要模型支持 tools/tool_calls。若返回 400 等错误，先核对模型支持能力；基础版不发送 tools。

## 验证

在本目录运行 `node tests/verify.cjs`。覆盖档案增改删、关闭读取、清空、确认、重复确认、版本冲突、拒绝无原文写入、检索命中/未命中、工具结果回传模型、关闭工具、基础版隔离、网络失败和密钥不持久化。所有 JavaScript 已通过 Node 语法检查。

没有用户 API Key，未执行付费真实模型调用；当前环境未在微信开发者工具模拟器或真机中实测，因此最终编译、域名和模型工具兼容性需在导入后验证。
